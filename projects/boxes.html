Boxes

Self-hosted platformDevelopment environments / App deployment

Persistent development containers, browser terminals, and GitHub-based app deployments on one machine you control.

From a repository to a running app. Select a stage.

    A small cloud of your own

    Boxes brings development environments and application hosting together on a single Docker host. A dashboard provides live state, logs, deployment history, resource limits, and encrypted environment variables.

    Persistent development

    Open a terminal in the browser, install tools, and run your own servers. Terminal sessions use tmux, and workspace storage survives restarts and container deletion.

    Deployment and access

    Deploy from a GitHub repository with a Dockerfile. Each application can have its own hostname and access policy. A Go controller manages container lifecycles, builds, health checks, and routing; PostgreSQL stores the platform’s state.

    Boxes is designed for one trusted operator on one machine. An optional Tailscale-connected edge supports hosting without opening inbound ports on that machine.
