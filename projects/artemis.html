--- layout: project title: Artemis project: artemis permalink: /projects/artemis/ --- ## Overview Artemis is a personal Raspberry Pi project that combines gesture recognition, voice interaction, and command handling. ## Implementation The project uses OpenCV for hand-signal recognition and connects a voice interface to an LLM-backed command flow. The public repository is linked above. ## Reflection It is an early exploration of multimodal interaction at the boundary between physical computing and AI. Its current status is not represented as an ongoing commitment here.
